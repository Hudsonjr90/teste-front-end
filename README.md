# Teste Front-End Econverse

A aplicacao foi implementada em React + TypeScript + Sass dentro da pasta [econverse-app](econverse-app).

## Executar localmente

1. Entre na pasta do projeto:

```bash
cd econverse-app
```

2. Instale as dependencias:

```bash
npm install
```

3. Rode em desenvolvimento:

```bash
npm run dev
```

4. Build de producao:

```bash
npm run build
```
